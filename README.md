# Ana Laudado, Product Designer

Live here: [https://anitalaudado.com](https://anitalaudado.com)

## Features

- On-demand ISR (Incremental Static Regeneration)
- TanStack Query
- Zod
- Tailwind
- Sanity for content management
- Dark theme
- Accessibility

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
heck out our [Next.js deployment documentation](https://nextjs.org/docs/app/building-your-application/deploying) for more details.
